## 2. 变更内容与视觉重构清单 (Implementation & Visual Refactor Summary)

### 2.1 视觉风格升级 (Visual Language Refactor)
- **大留白与清晰层级**：移除过重的沙色渐变、大块嵌套边框及营销文案，采用清爽白色卡片配合大留白与高对比数字层级。
- **模块标题**：统一使用 `"行程消费预估"`，严格禁止使用 `"预算参考"`。
- **左上全团总额展示区**：
  - `complete` 状态：展示 `"预估 ¥min–¥max"`。
  - `partial` 状态：展示 `"已估 ¥min–¥max"` 并附带 `"部分费用待确认"` 徽标。
  - `unavailable` 状态：展示 `"费用暂不可估算"`，禁止出现 `¥0`。
  - 场景状态标签（替换旧版“参考总预算·约占 85%”）：展示如 `高铁往返方案 · 完整预估`。不展示任何“人均”或“1人”假数据。

### 2.2 严格五类明细与动态金额条 (5 Categories & Dynamic Bars)
- **五类顺序保持**：严格维持服务端 5 类顺序（1. 大交通 2. 住宿 3. 市内交通 4. 景点门票 5. 餐饮），禁绝“其他”分类。
- **动态金额条比例**：
  - 基于服务端 `category.range.max_cny / maxCategoryMaxCny` 动态计算各分类相对比例（`width: ${percent}%`）。
  - 缺失分类（`missing`）渲染灰色虚线空轨与 `"待确认"` 徽标，禁止显示 `¥0`。
  - `policy_zero` 显式呈现 `"按规则计为 ¥0"`。
  - 下方使用低层级小字保留价格依据（`"来源查价 / 参考估算 / 来源与参考混合 / 按规则计为 ¥0"`）。

### 2.3 场景控制器与双场景未选中防泄露 (Segmented Control & Privacy Guard)
- **轻量 Segmented Control**：双场景使用轻量 Radio 按钮，支持 `role="radiogroup"`, `role="radio"`, `aria-checked` 及键盘方向键操作。
- **双场景未选防护**：
  - 双场景初始未选择时，标题区展示 `"选择大交通出行方案以查看预估"`，主区域展示 `"选择交通方式查看预估"`。
  - **全 DOM 无金额硬指示**：双场景未选择时，整个 DOM 中绝不存在任何 `¥` 符号或金额数字，防止提前泄露场景价格。
- **单场景自动激活**：单场景或 `without_intercity` 自动激活选中。

### 2.4 说明区与响应式布局 (Notes & Responsive)
- **说明区**：计算假设与免责放在卡片底部，保留 `"骑行费用暂未计入"` 等服务端事实。
- **移动端响应式**：
  - 第一行：`图标/分类 + 金额/状态`
  - 第二行：`金额条` 全宽展示，防止横向溢出。
- **页面位置**：卡片位于攻略末尾“出行与费用”附录区 (`#cost-estimate`)，大交通推荐卡片在费用卡之前。
